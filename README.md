# ТАБЕЛЬ

Простой адаптивный лендинг видеопродакшена по текстовому прототипу. HTML, CSS и JavaScript без зависимостей и сборки.

Дизайн: бумажный фон `#E9E4D8`, графит `#1F2428`, пыльно-голубые акценты, кирпичные метки и небольшие золотые символы. Шрифты Oswald, IBM Plex Sans и IBM Plex Mono подключены локально из `assets/fonts`; лицензии сохранены рядом.

## Запуск

Из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте порт 8000 в браузере. Также можно открыть `index.html` напрямую.

## Что работает

- Навигация по разделам и раскрывающийся FAQ.
- Адаптивная сетка для компьютеров и телефонов.
- Форма с проверкой обязательных полей и скачиванием заполненного брифа в TXT.

Форма не отправляет данные на сервер. Для публикации нужно добавить реальные контакты, согласованные работы, юридические сведения и подключить обработку заявок при необходимости. Демонстрационные обложки не являются клиентскими кейсами.
